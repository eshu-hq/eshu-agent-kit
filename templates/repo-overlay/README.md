# Repo overlay

This is everything a product repo keeps. Copy these two files, set the pin, run the installer.

## `.agent-kit-version`

One line: the kit tag this repo installs (for example `v0.1.0`).

## `AGENTS.md` (overlay)

Keep it to pointers: repo ownership, service boundaries, and the two or three docs that define this repo's contracts. Everything shared stays in the kit. See `AGENTS.md.overlay.example` in this folder.
