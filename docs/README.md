# eshu-agent-kit docs

Welcome. This kit is one shared set of skills, subagent roles, hooks,
and rules for every coding agent in eshu-hq repos, installed by version
instead of copy-pasted per repo. New here? Start with
[Getting started](getting-started/README.md).

| Section | What you'll find |
| --- | --- |
| [Getting started](getting-started/README.md) | Install the plugin or run `install.sh`, and make a first skill load |
| [Guides](guides/README.md) | Install per harness, pin a repo, choose models, upgrade |
| [Concepts](concepts/README.md) | The task-to-merged-PR loop, what you get, and the boundaries |
| [Reference](reference/README.md) | Counts, harness support, installer modes, and pin files |
